# CMS MPD Home

This vault separates raw imports, reviewed source notes, and stable topic knowledge so your Medicare plan study material stays manageable.

> [!info] Quick Start
> 1. Save imported markdown files into `01 Inbox/Articles`, `01 Inbox/References`, or `01 Inbox/Web Imports`.
> 2. Create a reviewed note in `02 Source Notes` with [[Article Note Template]] or [[Reference Note Template]].
> 3. Distill lasting knowledge into `03 Topic Notes` with [[Topic Note Template]].

> [!tip] Working Convention
> When repository implementation work is active, treat the `cms-mpd/` vault as the project knowledge base.
> Start from [[CMS MPD Home]] and [[CMS MPD Recommendation - Research Flow, Data Logic, and Algorithm]], then sync the vault after substantive pipeline, recommendation, modeling, or manuscript changes.

## Vault Layout

| Folder | Purpose |
| --- | --- |
| `01 Inbox` | Raw imported markdown files and unprocessed source material. |
| `02 Source Notes` | One reviewed note per article, document, or source. |
| `03 Topic Notes` | Stable knowledge notes for Medicare plan concepts. |
| `04 Study Notes` | Active study sessions, questions, and working notes. |
| `05 Outputs` | Summaries, exam prep, and reusable deliverables. |
| `06 Templates` | Reusable note templates for consistent capture. |
| `materials` | PDFs, images, and non-markdown source files. |
| `99 Archive` | Retired or superseded material. |
